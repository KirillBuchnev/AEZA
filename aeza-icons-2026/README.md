# Aéza icon set 2026

Набор иконок по гайдбуку Aéza: сплошная геометричная заливка, мягкие скругления и контрастные внутренние вырезы.

## В наборе

- `01-wallet` — кошелек
- `02-time` — часы / время
- `03-currencies` — доллар, рубль, евро
- `04-info` — информационный знак
- `05-warning` — предупреждение / ошибка
- `06-status-high` — высокая красная плашка
- `07-status-mid` — средняя желтая плашка
- `08-status-low` — низкая зеленая плашка

## Форматы

- `svg/` — редактируемые векторные исходники
- `png/` — PNG 512×512 с прозрачным фоном
- `preview/aeza-icons-preview.png` — превью на шахматном фоне

## Палитра

- Aéza blue `#4CC6F1`
- Black `#000000`
- Light gray `#F4F4F4`
- Orange `#E97C35`
- Navy `#182D48`
- Pink `#ECCFDB`
- Status red `#E84D5B`
- Status yellow `#F3C84B`
- Status green `#55C68B`

Иконки сделаны без внешней подложки, поэтому их можно ставить на темный, светлый или фирменный фон.

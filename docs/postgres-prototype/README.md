# Черновик переноса на PostgreSQL

Это ранний черновик другой реализации бэкенда, которую прислали отдельно (`backend1/`, `docker-compose1.yml`, `db/004_backend.*`). Он **не запускается** без правок: импортирует модули старой версии `backend/app` (`risk`, `schemas`) и использует более раннюю модель риска.

Что из него вошло в основной проект:

- данные кейса из `db/002_seed.sql` — загружаются по умолчанию (`AEZA_SEED=case`);
- выгрузка CSV/XLSX/XML — `GET /api/v1/export/...`, с исключением служебных таблиц.

Что осталось здесь как путь миграции: схема `db/004_backend.sql` описывает таблицы сессий, пользователей и настроек в PostgreSQL. Текущий рантайм использует SQLite (см. `PRODUCT.md`), переход на PostgreSQL — отдельная задача, если понадобится несколько экземпляров сервиса.
